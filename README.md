# Hochschulimkern Content Skill

Wöchentliches Content-Research und Ideation für die Hochschulimkern Social-Media-Kanäle (@ansbacher_hochschulbienen).

- `SKILL.md` — Workflow-Beschreibung für den Claude-Skill (Trend-Recherche, Stil-Analyse, Ideen-Generierung).
- `content-ideas-log.md` — Log aller vorgeschlagenen/gedrehten/geposteten Ideen, damit sich künftige Läufe nicht wiederholen.

Dieses Repo wird von einer wöchentlichen Cloud-Routine (montags) gelesen und aktualisiert. Es enthält bewusst keine Video-/Bilddateien — die liegen weiterhin lokal im Projektordner.
